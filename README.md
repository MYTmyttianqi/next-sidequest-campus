# 下一条支线

校园日常，也藏着另一条支线。

[在线体验](https://next-sidequest-campus.toasty-ape-9100.chatgpt.site) · 当前版本 v0.2.1

第一章 **《被复制的星期三》** 是一个约 6—10 分钟的原创互动短篇。玩家观察身边的小细节，写下三句话，选择自己的路线，最后得到一份可保存的冒险小册子。

## 这个版本可以做什么

- 完整的开场来信、三幕任务、两种结局。
- 第一幕的选择改变第二幕任务；第二幕影响后续提示与结局细节；最后一次选择决定结局。
- 用户写下的内容进入后续剧情、结局和小册子。
- 校园观察和原地观察两种入口；不需要定位或陌生人配合。
- 可选照片在浏览器本机缩小、重新编码并保存，也可以纯文字完成。
- 自动保存本浏览器进度，支持刷新、回看和修改。
- 下载包含文字与可选照片的完整离线 HTML 小册子。
- 下载 PNG 结局卡；浏览器打印或另存 PDF。
- 手机布局、键盘操作、清除旅程与隐私说明。

这是单人第一章。好友共同视角、多人协作、账号、云同步和付费章节还没有加入。

## 本地运行

需要 Node.js 20 或更新版本。项目没有第三方运行依赖，不需要安装依赖。

```text
npm run dev
```

打开终端提示的地址，默认为 `http://127.0.0.1:4173/`。按 Ctrl+C 停止。

请使用 HTTP 服务器打开；直接双击 `dist/index.html` 时，浏览器可能会阻止 JavaScript 模块加载。

## 检查

```text
npm test
```

8 项核心测试覆盖全部 8 种选择组合、进度恢复、损坏存档、输入限制、文本转义和离线导出。浏览器验收范围与待验证项目见 [VERIFICATION.md](VERIFICATION.md)。

## 发布与继续开发

`dist/` 是完整静态网站，可放在支持静态文件的托管平台。无需数据库、模型密钥或构建步骤。将 `dist/` 的内容作为网站根目录发布即可。

仓库保留完整源代码、原创素材、第三方素材许可与验收记录。网站托管账号的配置和浏览器本地用户记录不属于公开源码。

## 数据与限制

记录只保存在当前浏览器的本地存储里，不会由本应用上传。清除浏览器数据、更换设备或存储权限受限时，进度可能丢失。照片和笔记应通过下载的小册子自行备份。

单份照片上限为 10 MB，仅接受 JPG、PNG、WebP；在本机缩小并重新编码为 JPEG。手机相机特有格式可能需要先转换。结局卡导出文字摘要，完整照片在离线小册子中。

目前没有后台、公共个人手册链接、用户统计、支付或内容管理平台。是否让真实学生愿意完成、重玩、分享，仍需要小规模试用验证。
